# Core Loop

**전투 → 자원 확보 → 건설 → 연결 → 검증 → 재편 → 전투**

```mermaid
flowchart TD
    A[적 침입 감지 · 경로 분석] --> B[방어 지점 결정]
    B --> C[캐릭터 현장 개입 · 유도 · 포박 · 압축]
    C --> D[방어시설 집중 공격 · 대량 섬멸]
    D --> E[물자 · 정보 · 혼 확보]
    E --> F[시설 구축 · 병기 개조 · 관군과 주술 배치]
    F --> G[봉수망 연결 · 도시 방어망 확장]
    G --> H[다음 웨이브]
    H --> I{방어망 검증}
    I -->|방어 성공| J[영역 확장 · 자동화]
    I -->|약점 발생| K[방어선 재편]
    I -->|외곽 붕괴| L[후퇴 · 전장 압축]
    J --> A
    K --> B
    L --> B
    J --> M[한양 전체 네트워크화]
    M --> N[도시 자체가 전투 · 최종 백귀야행]
    N --> O{핵심 시설 생존}
    O -->|새벽까지 방어| P[런 승리]
    O -->|핵심 시설 파괴| Q[런 패배]
    I -->|최종 방어선 상실| Q
    P --> R[규장각 기록 · 전략 해금]
    Q --> R
    R --> S[다음 런]
    S --> A
```

## 시간 규모별 설계 가설

| 규모 | 반복 행동 | 관찰할 피드백 |
|---|---|---|
| 10~30초 | 위험 발견, 흐름 제어, 시설 사격 | 적의 집결과 누수 |
| 1~3분 | 확보, 건설, 개조 | 배치의 효과와 자원 부족 |
| 3~5분 | 연결, 사건 대응, 재편 | 연결망 변화와 약점 |
| 한 런 | 외곽에서 도시 전체로 확장, 필요시 후퇴 | 도시가 싸우는 완성감 |
| 런 사이 | 기록, 선택지 해금 | 다른 방어 전략 |

위 시간은 튜닝 가설이다. 첫 프로토타입은 짧은 고정 시나리오로 검증한다.

## 붕괴의 의미

외곽 시설 일부를 포기하고 남은 방어 수단을 안쪽 병목에 재배치한다. 후퇴 시 적 밀도가 증가하면서 집중 화력의 기회도 생긴다. 최종 핵심 시설이 파괴되면 런을 종료한다.

WP-001은 유도·압축·섬멸, WP-002는 연결에 따른 행동 변화, WP-003은 검증·붕괴·재편을 다룬다. 자원 경제와 장기 성장은 이 세 가설을 확인한 뒤 추가한다.
