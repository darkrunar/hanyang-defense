# 비주얼 레퍼런스

현재 제작 기준(2026-09-20): [ART_GUIDE](ART_GUIDE.md) · [ASSET_MANIFEST](ASSET_MANIFEST.csv) · [WP-005 READY](../../backlog/WP-005.md). 아래 두 이미지는 기존 기획 자료로 보존한다. 실제 제작에서는 사용자가 후속으로 제시한 작은 스프라이트·낮은 채도의 탑다운 픽셀아트 방향과 현재 게임 규칙을 우선한다.

작성일: 2026-09-13. 두 이미지 모두 AI 생성 기획 자료이며 실제 게임 실행 화면이 아니다.

## 콘셉트 아트

![콘셉트 아트](hanyang-defense-concept-01.png)

- 용도: 조선 사이버펑크 세계관·재료·조명·도시 방어망 분위기.
- 핵심: 장승으로 군집 압축, 포졸의 포박, 화차 집중사격, 봉수망으로 도시 연결.
- 해석: 영화적 구도와 세부 묘사는 분위기 참고. 플레이 카메라·실제 모델 복잡도의 확정 기준은 아니다.

## 예상 플레이 화면

![예상 플레이 화면 목업](hanyang-defense-gameplay-mockup-01.png)

- 용도: 실제 플레이에 가까운 카메라·스케일·경로·시설·HUD 배치 검토.
- 변화: 하늘과 원경 중심 구도에서 높은 전장 시점으로 전환하고 작은 캐릭터·세 진입로·건설 위치를 읽기 쉽게 표현.
- 해석: 이 목업을 화면 구성의 우선 참고로 사용한다. 수치·UI 문구·단축키·밸런스·엔진은 확정하지 않는다.
- 범위: 봉수망·경제 HUD까지 포함한 장기 방향이다. 초기 WP의 구현 범위는 해당 명세를 따른다.
