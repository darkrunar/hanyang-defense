## Goal / Player Experience

**같은 화차·같은 적 위치에서 봉수망 연결만으로 사격 가능 여부가 달라진다.**

독립 화차는 로컬 범위 밖 적을 모른다 → 센서·봉수대 설치 → 공유 표적 사격 → 연결 단절 → 로컬 탐지로 복귀 → 연결 복구와 재사격. 사거리·피해·발사 속도는 연결로 증가하지 않는다.

## Scope

봉수대 중계 그래프, 혼천의 센서 1종, 화차의 로컬 탐지·공유 표적 수신, 설치·제거·활성 전환, 연결/표적 상태 표시. WP-001의 후보 영역·밀도·광역 피해를 재사용하며 고정 fixture와 1000체 성능을 검증한다.

## 확정 동작 계약

### 연결·배치

- 활성 봉수대끼리 중심 거리 **180px 이하**면 무방향 간선으로 연결한다. 경계 포함, 지형 시야 차폐 없음.
- 센서·화차는 각각 180px 이내 **가장 가까운 활성 봉수대 하나**에 부착한다. 동률은 안정된 시설 ID 오름차순. 연결 변화 때 같은 규칙으로 재부착한다.
- 센서·화차는 중계하거나 서로 직접 연결하지 않는다. 단말이 두 망을 합치지 않는다. 봉수대 연결 요소의 최소 시설 ID를 그룹 ID로 사용한다. 부착할 봉수대가 없으면 그룹 없음이다. 장승은 네트워크 노드가 아니다.
- 봉수대·센서는 **2×2 점유, 적 통행 비차단**이다. 경계·지형·시설 중복·현재 생존 적 점유를 거절한다. 미리보기와 실제 설치는 같은 배치 검증을 사용한다.
- 비활성 시설은 점유를 유지하되 탐지·중계·사격을 멈춘다. 제거하면 점유도 해제한다. 장승 외 시설의 설치/제거/활성 전환은 경로 버전을 바꾸지 않는다.

### 탐지·사격

| 항목 | WP-002 초기값 | 판정 |
|---|---|---|
| 봉수대 연결 / 단말 부착 | 180px | 시설 중심 거리, 경계 포함 |
| 센서 탐지 | 140px | 센서 중심~생존 적 현재 좌표, 경계 포함 |
| 화차 로컬 탐지 | 100px | 화차 중심~생존 적 현재 좌표, 경계 포함 |
| 화차 사거리 | 200px | 화차 중심~후보 영역 중심, 경계 포함 |
| 피해 / 재장전 / 폭발 반경 | 34 / 0.8초 / 55px | WP-001 유지 |

- 화차가 아는 적 = 자신의 로컬 탐지 ∪ 같은 그룹 활성 센서들의 탐지. 화차 로컬 정보는 다른 화차에 재공유하지 않는다.
- 센서는 **개체 ID**를 공유한다. 중복 센서·로컬/공유 중복은 한 번만 센다. 풀 슬롯 재사용은 세대 또는 동등한 식별 방식으로 이전 개체와 구분한다.
- 후보 영역의 밀도는 그 영역 안의 **해당 화차가 아는 생존 적** 수다. 영역 일부만 관측했을 때 영역 전체의 적 수를 공유하지 않는다. 서로 겹치는 별도 후보 영역은 각자 집계한다.
- 알려진 적이 1 이상이고 영역 중심이 사거리 안인 후보 중 최고 밀도를 선택한다. 동률은 영역 ID 오름차순. 로컬/공유 출처에 우선순위는 없다. 공유해도 사거리 밖 표적은 발사하지 않는다.
- 광역 피해는 기존처럼 폭발 반경 내 모든 생존 적에게 한 번씩 적용한다. 미탐지 적도 폭발에 맞을 수 있지만 이를 탐지나 표적 선택에 소급 사용하지 않는다.
- 같은 틱의 앞 화차가 처치한 적은 뒤 화차의 알려진 집합·밀도에서도 제외한다. 발사 전에 최신 연결·활성·생존·범위를 확인한다. 연결 단절/복구는 쿨다운을 초기화하지 않는다.

### 갱신·기존 동작 보존

- 시설 변경 명령과 이동을 반영하고 **그 변경을 처리하는 시뮬레이션 틱의 사격 판단 전에** 그래프/부착/탐지를 갱신한다. 틱 사이 입력은 다음 틱 시작에 처리한다. 오래된 공유 표적을 한 발 더 쏘거나 TTL로 유지하지 않는다.
- 센서 제거/비활성·범위 이탈·적 사망·연결 단절 시 현재 탐지 출처가 없는 적만 폐기한다. 다른 센서나 로컬 탐지가 남으면 유지한다. 센서 없는 그룹은 공유 표적이 없다.
- WP-001 검증 모드는 기존 탐지·표적 규칙과 fixture를 유지한다. WP-002 모드에는 로컬 100px와 공유 제한을 적용한다. 기존 AC-06 수치를 WP-002 모드에 강요하거나 WP-002에서 전역 밀도를 사용하지 않는다. 모드·설정을 결과에 명시한다.
- 초기화 시 노드·부착·표적 캐시·누적 계수를 비우고 고정 fixture를 복원한다. 같은 시드·명령 순서에서 그룹·알려진 ID·표적·사격 집계가 재현돼야 한다.

1. B 비활성: 알려진 적 0, 발사 0.
