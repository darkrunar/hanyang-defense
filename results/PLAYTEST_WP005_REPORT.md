## 3. 발견 사항

1. **시나리오 문서 수정**: 외곽 HP 40이면 붕괴가 약 20~30초에 온다(t60에 이미 붕괴). 문서의 "40~60초"를 고쳤다.
2. **결과 메뉴는 별도 캡처로**: 스크립트 모드는 메뉴 우회(WP-004 §6)라 T4의 결과 화면·일시정지·설정은 `captures/menus/`의 샘플 아트 위 `wp004_ui`/`_720` 11장씩으로 확인한다. 사람이 하는 T4는 그대로 유효하다.
3. **디버그 오버레이**: 밀도 존·사거리 원은 기본 on이라 첫인상에 개입한다. 스타일 판단 시 `Z`·`G`로 끄도록 시나리오에 명시했고, `clean` 캡처를 함께 뒀다.
4. **미제작 표현이 드러나는 순간**: 붕괴 순간(효과 없음), 재배치(이동 연출 없음), 거점(도형), 통로(회색상자). 사용자 응답에서 이 항목은 "범위 밖"으로 안내했다.
5. **테두리·소등 표시**는 회차 5 렌더 보정이 실제 런에서 의도대로 동작했다(로그 `marks_drawn`, 캡처).
