# 플레이 테스트 시나리오 · WP-005 그래픽 샘플 (v1, 2026-09-20)

사용자가 실제로 플레이하며 **스타일 방향(AC-08)** 과 **가독성(AC-02/03/06)** 을 확인하기 위한 절차다. 응답은 아래 응답표에 적어 주면 Claude Code가 `results/WP-005-RESULT.md` "사용자 확인 기록"에 날짜·빌드·의견을 옮긴다. 무응답은 승인이 아니다. 판정은 사용자의 것이고, 이 문서는 무엇을 어디서 보면 되는지만 안내한다.

**이번 샘플의 범위 밖(보이더라도 미완이라 평가 대상이 아님)**: 광장·궁성 밖 통로의 회색 바닥, 바닥 가장자리(현재 절차적 선), 광화문 문, 외곽/핵심 거점 그림(현재 도형), 발사·탄착·붕괴 효과(현재 도형), 화차 발사·봉수 점등 애니메이션, 글꼴. 이들은 GPT 제작 대기 목록이다.

## 1. 시나리오 (총 15~20분)

### T0 · 조작해 보기 (연습 모드, 5분)

일반 런(WP-003 계약)은 붕괴 뒤 회수 화차 배치 한 번이 플레이어의 유일한 결정이라, 기본 외곽 HP 360에서는 조작할 것이 거의 없다. 조작감을 보려면 **연습 모드**로 실행한다(같은 샘플 아트, 시설 자유 설치):

```bash
godot --path . --rendering-driver opengl3 -- --set=run_mode=sandbox --set=fixture=b
```

- `1`~`4`로 장승/화차/봉수대/혼천의 설치 모드, `LMB` 설치(누르고 있으면 재시도), `RMB` 철거, `T` 커서 아래 시설 활성/비활성, `C` 전투 토글. 적은 1,000체가 계속 유지된다.
- 해 볼 것: 남문 서편 골목 (44,36) 부근에 장승을 놓아 흐름이 동편으로 옮겨가는지, 봉수대 B8을 `T`로 꺼서 남쪽 혼천의 공유가 끊기는지(가이드 10절).
- 이 모드의 조작·규칙은 WP-001/002 것이고, 일반 런에 건설을 넣을지는 GPT 판단(P-019)이다. 질문 Q0: 조작감(설치·철거·반응)이 이 그림 위에서 어떤가.

### T1 · 첫인상 (시작 → 15초)

1. 시작 화면에서 **게임 시작**. 아무 조작 없이 15초 관찰.
2. 볼 것: 광장 바닥·지붕(청회색 기와)·담장, 시설 4종(화차 4·봉수대 8·혼천의 4·장승 2), 적(적갈색 12×16, 밝은 테두리), 광장 밖 회색 통로와의 경계. 밀도 존·사거리 원(디버그 오버레이)은 `Z`·`G`로 끄고 보는 것을 권한다.
3. 질문 Q1~Q5.

### T2 · 밀집 전투 (60~100초)

1. W2~W3 구간(화면 상단 HUD `웨이브 W2/W3`)에서 남대문 골목과 광장 남쪽을 본다. `Z`로 밀도 존, `G`로 사거리 원을 켜고 끈다.
2. 볼 것: 적 군집이 길을 따라 흐르는지, 화차 사격(조준선·탄착 원)이 어느 군집을 치는지, 장승이 막은 골목이 읽히는지.
3. 질문 Q6~Q7. (참고: 일반 런의 동시 생존은 최대 200체 안팎이다. 1,000체 화면은 `results/evidence/wp-005/captures/wp005_dense_*.png`로 별도 제공.)

### T3 · 붕괴와 회수 배치

1. `-- --set=outer_hp=40`으로 다시 실행하면 약 20~30초에 외곽이 붕괴한다(실측: 60초 캡처에서 이미 붕괴). 기본값 360에서는 외곽 도달 360체가 쌓여야 붕괴해 대개 외곽을 지킨 채 이긴다.
2. 붕괴 순간: 외곽 시설이 소등(회색·사선 표시), 우상단에 "화차·중영 회수 대기 1/1", 내곽 테두리 굵게.
3. 내곽(궁성 구역)의 빈 2×2칸에 마우스를 올려 **초록(가능)/빨강(불가)** 테두리를 본 뒤 클릭해 배치한다. 추천 자리: 봉수 B2 옆 (900,280) 부근. 외곽이나 벽·다른 시설 위는 거절된다.
4. 볼 것: 소등 시설과 활성 시설이 라벨 없이(`L`) 구분되는지, 회수된 화차 자리가 비고 대기 슬롯에 보이는지, 배치 후 새 자리에서 사격하는지.
5. 질문 Q8~Q10.

### T4 · 메뉴·결과 화면

1. 전투 중 `Esc` → 일시정지 → 설정(창 모드↔전체화면 전환) → 뒤로 → 계속하기.
2. `R` → 확인창(기본 포커스 취소) → 취소. 결과 화면(승리 또는 패배)까지 진행 후 미니맵·수치 확인, 다시 시작.
3. 창을 1280×720으로 줄여 같은 메뉴를 한 번 더 연다.
4. 질문 Q11~Q12.

### T5 · 비교 (선택, 5분)

1. `-- --art=greybox`로 같은 런을 15초 본 뒤 `sample`과 비교한다. 같은 시드라 전투는 동일하고 그림만 다르다.
2. `-- --art-outline=off`로 적 테두리를 끄고 어두운 통로 위 적을 비교한다.
3. 질문 Q13~Q14.
