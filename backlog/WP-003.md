## Goal

적이 방어망의 약점을 드러내고, 외곽 붕괴 후 내곽에 재배치해 다시 싸울 수 있는 짧은 시나리오를 만든다.

## Player Experience

외곽 방어 → 누수와 거점 피해 → 외곽 붕괴 → 내곽 후퇴 → 화차 재배치·봉수망 재연결 → 집중 방어 → 승리 또는 패배.

## Scope

외곽/내곽 두 구역, 거점 HP, 고정된 짧은 웨이브, 붕괴 이벤트, 적 목표 갱신, 화차 1대 회수·재배치, 승패와 재시작. 기존 경로·시설·봉수망을 연결한다. 고속 적 또는 추가 진입로로 약점을 드러내되 READY 전환 시 한 가지를 선택한다.

## Non-Goals

완성형 경제, 무작위 사건 전체, 보스, 메타 성장, 30분 런, 최종 캐릭터 조작.

## Acceptance Criteria

| ID | 합격 조건 | 검증 |
|---|---|---|
| AC-01 | 외곽 HP 0에서 붕괴가 한 번만 발생하고 게임이 계속된다 | 중복 피해 이벤트와 상태 전이 로그 |
| AC-02 | 기존 생존 적과 신규 적 모두 내곽으로 이동하며 폐기된 목표에 남지 않는다 | 붕괴 직전/직후 생성 사례 |
| AC-03 | 외곽 시설·연결은 비활성화되고 지정 화차 1대만 내곽에 재배치할 수 있다 | 중복 회수·배치 제한·표적 공유 검사 |
| AC-04 | 재배치로 새 병목에 화력을 집중하는 과정을 재현할 수 있다 | 동일 시드 재편 전후 밀도·처치·누수와 실제 화면 |
| AC-05 | 핵심 HP 0은 패배, 모든 웨이브·적 소진과 생존은 승리다 | 각 종료 및 동시 조건의 패배 우선 검사 |
| AC-06 | 종료 후 생성·피해가 멈추고 재시작 시 모든 런 상태가 초기화된다 | 승리·패배 후 각각 재시작 검사 |
| AC-07 | WP-001/002 회귀와 합의된 1,000개체 예산을 붕괴·재편 중에도 충족한다 | 상태 전환을 포함한 실행·성능 측정 |
