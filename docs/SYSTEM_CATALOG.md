## 미결정 사항과 적용 규칙

1. 최종 방어 대상, 적 도달 후 행동, 플레이어 직접 조작, 승리 조건은 재구축 Q1~Q5에서 재확인한다. 기존 구현 계약은 새 결정 전까지 보존한다.
2. 화차 탐지=사거리, 봉수/혼천의 보류는 이전 GPT 제안이며 사용자 확정이 아니다. S-06을 자동 삭제하지 않는다.
3. 장승 전승 명칭에 공격·회복·속성 능력을 자동 부여하지 않는다. L-ID별 자료 선정 이후 별도 규칙으로 정의한다.
4. 이번 확인에서 README·테스트 러너·맵 에디터 관련 미커밋 작업이 존재했다. 해당 변경은 보존하며 본 목록의 문서 커밋과 분리한다. 체크리스트의 ‘확정’ 표현만으로 기존 DECISIONS 전체가 대체됐다고 판단하지 않는다.
5. 콘텐츠/시스템 추가 시 ID·상태·근거·담당 WP·검증 질문을 먼저 기입한다. GPT는 기획·리뷰, Claude는 구현·시험·증거를 담당한다. 기존 AC와 10계명 적용 프로세스를 따른다.
