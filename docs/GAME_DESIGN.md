# Game Design

## 확정된 방향

**한양 전체를 무기화하는 대규모 전투 디펜스.** 장르는 조선 사이버펑크 로그라이트 디펜스이며, 플레이어의 현장 개입과 도시 방어시설의 자동 전투를 결합한다.

핵심 질문은 “어디에서 싸우게 만들 것인가?”다. 성문·골목·수로로 적의 흐름을 바꾸고 장승으로 병목을 만들며 화차와 봉수망으로 집중 공격한다. 후반부에는 한양의 연결된 방어체계가 여러 전선에서 싸우는 경험을 목표로 한다.

## 설계 원칙

- 캐릭터는 유도·포박·차단·수리·재배치로 도시의 화력을 작동시킨다.
- 시설은 지속 화력, 지형은 흐름 제어, 봉수망은 정보 공유와 연계를 담당한다.
- 연결은 수치 보너스뿐 아니라 새로운 행동을 만든다.
- 웨이브는 방어망의 약점을 드러내며 재편을 요구한다.
- 외곽 붕괴는 후퇴와 전장 압축으로 이어진다. 최종 핵심 시설의 상실이 패배 조건이다.
- 로그라이트 성장은 도시 기능의 해금·융합과 전략의 변화를 중심으로 한다.

## 플레이 경험과 범위

| 층위 | 경험 | 초기 구현 범위 |
|---|---|---|
| 순간 전투 | 위험 발견 → 적 유도·압축 → 시설 섬멸 | WP-001: 경로·장승·화차 |
| 도시 연결 | 시설 구축 → 봉수망 연결 → 표적 공유 | WP-002: 작은 단일 연결망 |
| 방어선 재편 | 약점 발견 → 붕괴 → 후퇴 → 새 병목 | WP-003: 외곽/내곽 두 구역 |
| 런 성장 | 자원·거점·보스에 따른 선택과 융합 | 후속 WP |
| 메타 성장 | 규장각 기록 → 새로운 시작 조건 | 후속 WP |

완성형 런은 약 25~30분, 동시 적 1,000~5,000개체를 탐색 목표로 둔다. 확정 성능 보장이나 초기 프로토타입 요구 전체가 아니다. 첫 검증은 동시 생존 1,000개체부터 시작한다.

## 세계관·아트 방향

성문은 방어 구역 경계, 봉수는 통신망, 혼천의는 센서, 자격루는 동기화 장치, 화차는 집중 사격 플랫폼, 주술은 전장 제어로 재해석한다. 먹색·청동·단청색·한지·전자광을 조합한다.

기존 대화의 ‘야경꾼 2092’, ‘천리경’, 전자 요괴 발생 설정은 세계관 후보이며 정식 명칭은 미확정이다. 원본 참조 이미지의 세부 디자인은 이 저장소에서 검증하거나 복제하지 않았다.

## 캐릭터와 시설 후보

초기 캐릭터에 **포졸·사또**를 포함하는 방향을 유지한다. 포졸은 포박·차단, 사또는 지휘·징발을 중심으로 설계한다. 무당·화포수·선비·나장 및 추가 세력은 확장 후보이며 초기 출시 인원은 확정하지 않는다.

화차(광역 화력), 장승(길 차단), 봉수대(연결), 혼천의(탐지)를 우선 검증한다. 신기전·관군·주술진·자격루 등은 후속 확장이다. WP-001의 건설 조작은 임시 인터페이스이며 완성형 캐릭터 조작은 별도 설계한다.

## 적·보스와 성장 후보

대량형, 고속형, 공성형, 영체형, 다방향 침입으로 방어망의 서로 다른 약점을 시험한다. 불가살이의 병기 흡수, 두억시니의 성벽 파괴, 용왕의 수로 변화는 보스 후보로 둔다.

물자는 시설, 정보는 경로·약점 예측, 혼은 주술과 고위험 강화를 담당하는 기획 자원이다. 구체적 경제와 획득량은 미정이다. 거점 확보·정예 처치·보스 처치 등 여러 행동에 성장 선택을 연결한다.

## 재미 검증

동일 적 유입에서 배치 변경 전후의 밀집도, 시설 처치 수, 누수 수를 비교한다. 플레이어가 약점과 재편 이유를 설명할 수 있어야 한다. 후반 경험의 성공 기준은 ‘한양 방어망이 완성됐다’는 인상이다. 이 정성 기준은 플레이테스트로 확인하며 FPS만으로 대신하지 않는다.

### 1. 세계관과 분위기: 콘셉트 아트

![한양 전체가 싸우는 밤 — 콘셉트 아트](art/hanyang-defense-concept-01.png)

성문·골목·수로가 연결된 방어망, 장승 병목, 포졸의 포박과 화차 집중사격을 표현한다. 먹색 기와·청동·따뜻한 포화·청백색 연결광을 아트 방향의 참고로 사용한다. 영화적인 원근과 높은 밀도는 분위기 표현이며 실제 플레이 화면의 기준으로 고정하지 않는다.

### 2. 화면 구성: 예상 플레이 목업

![높은 시점의 세 진입로 방어전 — 예상 플레이 목업](art/hanyang-defense-gameplay-mockup-01.png)

콘셉트 아트가 너무 회화적이라는 피드백을 반영해 실제 플레이에 가까운 높은 시점, 작은 플레이어와 적, 식별 가능한 진입로·화차·봉수망·건설 위치로 조정했다. 화면 구성 검토에는 이 목업을 우선 참고한다.

- 중앙 포졸과 적 흐름, 시설 사격을 한눈에 구분한다.
- HUD 예시는 웨이브·시간·거점 HP·자원·건설 도구·미니맵으로 구성한다.
- 숫자, 영어 라벨, 단축키, 캐릭터 HP와 건설 슬롯은 예시이며 확정 UI 명세가 아니다.
- 봉수망은 WP-002, 경제와 완성형 HUD는 후속 설계 범위다. 이미지가 WP-001의 Scope를 변경하지 않는다.
- 화면 속 적 수나 프레임 성능은 실측 결과가 아니다. 동시 1,000개체 목표는 구현 후 별도 검증한다.

두 이미지 모두 내장 image_gen으로 생성한 시각 자료이며 실제 빌드의 캡처가 아니다. 구현 기준은 SYSTEM_SPEC과 해당 WP의 수용 기준을 따른다.
