## 이후 후보

1. 포졸의 유도·포박과 사또의 지휘 등 캐릭터 현장 개입.
2. 물자·정보·혼 경제, 건설 비용, 회수와 자원 부족의 선택.
3. 거점·정예·보스 기반 로그라이트 선택과 도시 기능 융합.
4. 적 역할과 지형 변경 사건, 방어망을 바꾸는 보스.
5. 여러 구역의 동시 전투, 5,000개체 성능 탐색, 가독성 개선.
6. 규장각 해금, 런 전체 구성, 아트·사운드 제작.

후속 항목에는 일정과 완료 약속을 부여하지 않았다. 플레이테스트에서 ‘배치 변경이 전투 결과를 바꾸는가’, ‘연결이 새로운 행동을 만드는가’, ‘후퇴가 다시 설계할 기회를 주는가’를 먼저 확인한다.

자동화는 수동 문서 핸드오프 → Git/PR 기반 반자동 → 별도 오케스트레이터 순서의 후보로 둔다. 초기 저장소에는 자동 실행을 구축하지 않는다.
