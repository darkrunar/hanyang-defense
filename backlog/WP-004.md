## Goal

시작 화면 → 전투 → 일시정지 → 승패 결과 → 다시 시작을 연결하여 같은 전장을 반복 플레이하고 배치 선택을 비교할 수 있게 한다. WP-003의 전투 규칙·밸런스·회수 제한·승패 우선순위는 그대로 유지한다.

## Scope / Non-Goals

포함: 시작 화면, 일시정지 메뉴, 진행 중 재시작/시작 화면 복귀 확인, 승패 결과, 설정 진입/복귀, 창 모드 저장, UI 입력 차단, 실제 화면과 상태 전이 검증.

제외: 런 중간 저장/이어하기, 새 맵·랜덤 시드·난이도 선택, 재화/메타 성장, 리더보드·통계 누적, 게임패드, 전장 에셋 전체 교체, 음악/효과음·화면 흔들림/섬광 기능 신설. 설정값만 저장한다. 경제·음향·효과를 이번 메뉴 작업에 끼워 넣지 않는다.

## 1. 화면과 이동

| 상태 | 화면·버튼 | 처리 |
|---|---|---|
| TITLE | 게임 시작 / 설정 / 종료 | 최초 일반 실행 화면. 배경은 정적이어도 됨. 실제 전투는 진행하지 않음 |
| PLAYING | 전투 HUD / 일시정지 버튼 | WP-003 조작 유지. Esc 또는 P로 일시정지 |
| PAUSED | 계속하기 / 설정 / 다시 시작 / 시작 화면으로 | 전장을 배경으로 표시. 전투·배치 정지 |
| SETTINGS | 창 모드 / 뒤로 | 들어온 TITLE 또는 PAUSED로 복귀. 플레이 중 직접 열면 먼저 일시정지 |
| CONFIRM | 확인 / 취소 | 진행 중 런을 버리는 재시작·시작 화면 복귀 확인 |
| RESULT | 결과 요약 / 다시 시작 / 시작 화면으로 | WON/LOST가 확정되면 자동 진입. 전투는 종료 상태 유지 |

런의 RUNNING/WON/LOST, 방어선 OUTER_ACTIVE/INNER_ONLY와 UI 상태를 분리한다. 메뉴를 열었다는 이유로 런을 승리/패배 처리하거나 HP를 변경하지 않는다. 단일 상위 UI 상태와 설정/확인창의 돌아갈 위치를 명시한다.

- TITLE의 게임 시작은 초기 데이터로 새 런을 시작한다. 이전 런이 있더라도 이어하지 않는다.
- RESULT의 다시 시작은 확인 없이 즉시 새 런, 시작 화면으로도 확인 없이 이동한다.
- PLAYING에서 R은 재시작 확인창을 열며 즉시 초기화하지 않는다. PAUSED의 다시 시작도 같은 확인창이다. RESULT에서 R은 다시 시작 버튼과 동일하다.
- 재시작 확인 문구: **“현재 전투를 종료하고 처음부터 시작할까요?”** 버튼은 “다시 시작” / “취소”.
- 시작 화면 복귀 문구: **“현재 전투를 종료하고 시작 화면으로 돌아갈까요? 진행 상황은 저장되지 않습니다.”** 버튼은 “시작 화면으로” / “취소”.
- 확인창 취소/Esc는 원래 상태로 돌아간다. PLAYING의 R에서 열었다면 전투 재개, PAUSED에서 열었다면 일시정지 유지. 기본 포커스는 취소.
- SETTINGS의 Esc는 들어온 메뉴로만 복귀한다. PAUSED에서 다시 Esc는 전투 재개. CONFIRM 위에서 Esc는 취소만 한다. 같은 Esc 이벤트로 두 단계를 연속 닫지 않는다.
- TITLE/RESULT의 Esc는 종료/재시작을 실행하지 않는다. 종료는 TITLE의 명시적 종료 버튼으로 제공한다. 기존 일반 플레이의 Esc 즉시 종료 동작은 메뉴 진입으로 대체한다. 운영체제 창 닫기는 정상 종료하되 런 저장은 하지 않는다.
- SETTINGS/CONFIRM에서는 R/P 등 전투 단축키를 실행하지 않는다. 버튼 연타는 화면 전이를 한 번만 수행한다.

## 2. 정지·재개·입력 경계

- PAUSED/SETTINGS/CONFIRM/TITLE에서는 전투 틱을 진행하지 않는다. 적 생성/이동/사격/피해·쿨다운·웨이브 타이머·회수 배치를 모두 멈춘다. 메뉴 UI와 포커스·애니메이션은 반응한다.
- 멈춘 시간만큼 재개 직후 시뮬레이션을 몰아서 처리하지 않는다. 플레이 시간·붕괴 시각은 실제 전투의 시뮬레이션 시간 기준으로 표시한다.
- 메뉴에 진입할 때 전장 held click·재시도·회수 미리보기 등 pending 입력을 비운다. 메뉴를 닫는 클릭/Enter/Esc는 UI에서 소비하고 전장에 전달하지 않는다. **새 전장 입력은 메뉴를 닫은 입력이 해제된 뒤 새로 누른 입력부터** 받는다.
- 새 런/시작 화면 복귀 시 run_id와 pending 입력을 무효화한다. 새 런은 일시정지 해제·선택/hover/잔상/이전 결과 초기화 상태다. 이전 런 ID의 지연 명령이 새 회수권을 소비하지 않아야 한다.
- 같은 프레임에서 런이 이미 WON/LOST로 확정되면 RESULT가 우선한다. 아직 처리하지 않은 pause/restart 입력이 결과를 덮거나 자동 새 런을 만들지 않는다.
- 설정·메뉴는 회수권을 추가하거나 배치 검사(현재 적 점유·구역·지형·중복)를 우회하지 않는다.

## 3. 다시 시작 계약

같은 맵·시드20260913·초기18시설·10존·HP360/60·웨이브1140체로 시작한다. HP/적/시설/봉수망/목표/회수권/웨이브 예산·타이머/집계/RNG·입력 상태를 초기화한다. 새 런은 기존 WP-003의 새 Battle 초기 상태와 같아야 한다(run_id와 저장된 화면 설정 제외).

진행 중 취소하면 확인창 진입 시점의 전투 상태를 보존한다. 시작 화면으로 복귀를 확정하면 현재 런을 폐기한다. 다시 게임 시작 시 항상 새 런이다. 설정은 유지한다. 진행 중 재시작은 이번 선택을 다시 시험하는 기능이며 새 시드 뽑기가 아니다.

## 5. 설정과 시각 방향

현재 필수 설정은 **창 모드 / 전체화면**이다. 기본은 기존 창 모드·논리1920×1080을 유지한다. 변경은 즉시 적용하며 사용자 설정 파일에 저장한다. TITLE/PAUSED에서 같은 값을 보이고 앱을 다시 실행해도 유지한다. 설정 파일 없음·형식 오류·범위 밖 값이면 기본값으로 시작하고 실행을 막지 않는다. 저장 실패 시 화면에 알리고 현재 세션에서 계속 사용할 수 있게 한다.

음량(전체/음악/효과음), 화면 흔들림·섬광 강도는 해당 기능이 실제 구현된 시점에 추가한다. 이번 WP에는 동작하지 않는 슬라이더를 만들지 않는다. 런 상태·결과는 저장하지 않는다.

메뉴는 사용자가 제시한 탑다운 픽셀아트 방향에 맞춰 단순한 테두리·낮은 채도·명확한 버튼으로 제작한다. 조선의 목재/돌/기와 색, 청록 봉수망·주황 화차·붉은 위협 색을 참고한다. 한글은 가독성을 우선하며 외부 게임의 아이콘/텍스처를 가져오지 않는다. 1920×1080 및1280×720에서 클릭 영역/글자/포커스가 잘리거나 겹치지 않게 한다. 메뉴가 닫히면 기존 전장/HUD 배치를 복원한다. 전체 전장 픽셀아트 제작은 후속 작업이다.

## 6. 기존 실행·증거 모드 보존

일반 실행만 TITLE을 기본으로 한다. 기존 `--perf`, `--capture`, 헤드리스 테스트/장부 도구는 메뉴를 우회하여 원래 시나리오를 시작한다. 모드 구분을 이름 표시만으로 처리하지 말고 실제 Battle 설정·존/시설·런 상태를 확인한다. 기존 자동화의 scripted Esc 종료는 유지할 수 있다.

결정적 검증 모드는 사용자 설정 파일을 읽거나 수정하지 않는다. 성능은 기존1920×1080/vsync0 조건을 명시적으로 적용한다. 설정 저장 시험은 별도 임시 경로를 주입해 사용자의 실제 설정을 훼손하지 않는다. 기존 WP-001/002/003 증거를 덮어쓰지 않고 새 결과를 WP-004 아래에 둔다.
