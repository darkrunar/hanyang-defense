## WP-001 구현 중 발견한 제안 (GPT 검토 대상)

| ID | 제안 | 상태·이유 |
|---|---|---|
| P-007 | 포화 골목의 장승 설치 규칙 재검토 | 제안. "적이 점유한 위치에는 장승을 놓을 수 없다"(P-004 계열 규칙)를 그대로 구현하면 1,000개체 포화 상태에서 남대문 골목 2x2 앵커의 설치 성공률이 3.6~11.4%로 측정됨(`game/tools/probe_occupancy.gd`, tests AC-03 saturation case). 규칙은 명세대로 동작하지만 실전에서 병목을 "만드는" 조작이 재시도 의존적이 된다. 대안: (a) 현행 유지 + 마우스 홀드 재시도(현재 구현), (b) 설치 시 점유 적을 인접 통행 셀로 밀어내기, (c) 설치 예약 후 셀이 비는 순간 자동 확정. 게임 규칙 변경이므로 구현하지 않고 제안만 남김 |
| P-008 | 서·동대문의 남편 골목은 평시 미사용 | 관찰. 목표가 북쪽에 있어 서·동 경로의 남편 골목은 북편 골목이 막혔을 때만 쓰이는 우회로가 된다(AC-03 테스트로 검증). 남대문 두 골목은 대칭이라 자연 분산된다. 의도된 우회로로 볼지, 지형을 바꿔 평시에도 분산시킬지는 기획 판단 |
| P-009 | 밸런스 초기값 | 관찰. 적 HP 60 / 화차 피해 34 / 재장전 0.8s / 폭발 반경 55 / 사거리 200 은 "골목 통과 중 2발로 처치"가 성립하도록 맞춘 값이다(피해 25·재장전 1.2s에서는 골목 화차의 처치가 0이었음). 모든 값은 game/core/config.gd에 있으며 `--set key=value`로 바꿀 수 있다. 재미·난이도 튜닝은 범위 밖 |
