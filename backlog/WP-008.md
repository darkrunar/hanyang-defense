## 호환성과 진입

PREPARING에는 생성·전투·웨이브 타이머가 진행되지 않고 시간 제한이 없다. 시설 선택·배치와 메뉴 이용 가능. 방어 시작은 1회만 처리하고 런 시간/웨이브를 0부터 시작한다. 건설 메뉴 자체는 전투를 멈추지 않는다. Esc/P 메뉴는 기존처럼 멈춘다. 준비 중 메뉴를 닫으면 준비 상태로 복귀한다.

## 경제·건설 규칙

1. 물자는 정수·런 한정. 실제 살아 있던 적의 최초 처치 전이만 지급. 거점 도달·디버그 삭제·중복 이벤트는 보상 없음. 다수 동시 처치는 각 개체 1회.
2. 웨이브 소속 예정 적이 전부 생성되고 그 소속 적이 모두 처치/도달 등으로 해소되었을 때 해당 웨이브 보상 1회. 생성 종료만으로 지급하지 않음. 마지막 웨이브도 동일, 패배 확정 시점 이후 보상 없음. 같은 tick의 기존 사격→도달→승패 처리 순서를 보존하고 경제 정산 순서를 기록/테스트한다.
3. 준비와 전투 중 네 시설을 건설 가능. 검증과 차감/생성은 원자적 1회 처리. 잔액 부족·적 점유·시설 겹침·벽/맵 밖·구역 경계·전체 경로 차단·상한 초과·상태 불가 시 물자와 전투 상태 불변. 마지막 허용 슬롯에서 중복 입력해도 상한 초과 금지.
4. 1~4 또는 건설 버튼으로 종류 선택, 미리보기에서 비용/잔액/거절 이유 표시. LMB 새 누름 1회당 유료 건설 최대 1개. 누른 채 여러 셀을 지나도 연속 구매 금지, 실패 후 자동 재구매 금지. UI 클릭이 전장 클릭으로 새지 않게 처리한다.
5. 시설 상한은 초기+구매+비활성+회수 대기 시설을 포함한 총수. 회수/재배치는 새 구매가 아니므로 총량 변화 없음. 화차·봉수·혼천의는 통행 비차단, 장승만 기존 경로 검사 적용. 건설 완료 시 기존 봉수망/탐지/타기팅 갱신 경로 사용.
6. 외곽 붕괴 전에는 유효한 내·외곽 셀 건설 허용. 이후 유료 건설도 내곽만 허용. 외곽 기존/구매 시설은 기존 규칙대로 비활성·점유 보존. 무료 회수는 초기 중영 1대만, 구매 화차는 자동 회수하지 않음.
7. ‘회수 화차 배치’는 유료 건설과 별도 선택 상태·문구. 붕괴 때 회수 모드로 안내하되 유료 건설과 전환 가능. 무료 회수는 비용 0·동일 ID/쿨다운 유지. 기존 회수의 길게 누르기 재시도는 유지하고 유료 건설에 적용하지 않음.
8. 판매·철거·환불·강화·수리는 제외. 새 모드에서 sandbox 우클릭 철거/T 활성 토글/C 전투 끄기 사용 불가. 모드 전환/메뉴/재시작 시 미완 입력 해제. 승패 결과·일시정지·확인창에서는 건설/보상 진행 금지.
9. 재시작은 같은 seed의 새 준비 상태, 초기 4시설/물자240/보상 장부 초기화. 이전 런 이벤트로 새 런에 지급 금지. 결과에 획득/소비/잔액·건설 수 요약 추가(전체 UI 재설계 제외).
