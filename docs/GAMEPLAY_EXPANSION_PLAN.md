# 게임플레이 확장 계획 — 건설에서 공성·재편까지

2026-09-20 / D-054 / 계획 채택, 구현 미착수

## 목표와 플레이 순서

최소 시설과 시작 물자로 첫 방어선을 구성 → 넓은 성밖에서 적 무리 접근 → 성문 공방 중 물자 확보·추가 건설 → 성문 파괴 후 시가전 → 장승으로 유도·병목 형성 → 공성 적의 장승 파괴 → 내곽 후퇴·회수·증설 → 최종 방어.

이 흐름은 최종 목표이며 모든 단계가 현재 구현되어 있다는 뜻은 아니다. 참조 게임의 자산을 복제하지 않는다.

## 개발 순서

| 단계 | 상태 | 범위 | 선행 조건 |
|---|---|---|---|
| [WP-008 건설·물자](../backlog/WP-008.md) | READY | 준비 배치, 전투 중 유료 건설, 처치/웨이브 보상, 붕괴 후 회수와 내곽 증설 | WP-004 DONE 기반. WP-005와 독립한 게임플레이 트랙 |
| [WP-009 성밖·성문](../backlog/WP-009.md) | DRAFT | 넓은 외부 집결, 공격 방향 예고, 성문 HP·공격·파괴·통로 개방 | WP-008 DONE/PASS 뒤 지도·타기팅·성능 명세 확정 |
| [WP-010 장승 파괴](../backlog/WP-010.md) | DRAFT | 일반 적 우회, 공성 적의 장승 공격, 파괴 후 경로 재계산 | WP-009 DONE/PASS 뒤 공격 규칙 확정 |

플레이 순서와 개발 순서를 구분한다. 먼저 건설이라는 대응 수단을 제공한 뒤 성문·장승이 무너지는 위협을 추가한다.

## 그래픽 트랙과 관계

WP-005의 V-01~04 개선 계획은 유지한다. WP-008은 기존 샘플/대체 도형으로 검증 가능하며 WP-005 최종 스타일 승인에 의존하지 않는다. 독립 트랙은 별도 브랜치/PR/결과 문서로 관리하고 동일 에이전트가 두 WP 구현을 한 번에 섞지 않는다. 공통 파일 변경은 기준 SHA와 병합 뒤 회귀를 기록한다.

WP-006 전체 맵 아트 확장은 WP-005 스타일 승인과 WP-009 지도 구조 확정 이후로 이동한다. 성문/외부 지도 확정 전 기존 맵 전체를 먼저 꾸며 재작업을 만들지 않는다. WP-007 전체 UI/연출 마감은 새 건설 UI·공성 상태가 확정된 후 진행한다. 두 WP 모두 DRAFT 유지.

## 확정 방향과 미확정 항목

- 확정: 첫 재화는 물자 1종, 시작 물자 + 적 처치 + 웨이브 완료 보상. 시설은 장승·화차·봉수·혼천의. 일반 적은 우회, 공성 적은 장승 파괴 역할.
- 확정: 성문 파괴와 외곽 거점 붕괴는 별도 사건. 성문 파괴만으로 모든 외곽 시설이 꺼지거나 회수되지 않음. 외곽 거점 HP가 0일 때 기존 후퇴·재편 발생.
- 확정: 장승 전체 경로 차단 거절은 첫 확장에서도 유지. 완전 봉쇄를 허용하고 적이 반드시 뚫는 규칙은 후속 후보.
- 미확정: 외부 지도 크기·카메라, 성문 개수/HP, 적 대성문 공격력·동시 공격 슬롯, 공성 적 비율/타깃 선택/장승 HP. WP-009/010 READY 전에 확정하며 구현자가 임의 채택하지 않음.
- 이번 제외: 정보·혼·메타 성장, 시설 강화/수리/판매, 보스·캐릭터 스킬, 신규 최종 아트 양산.
