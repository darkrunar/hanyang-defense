## 목표와 범위

광화문 앞 한 구역에서 적 이동·화차 발사·봉수 연결·외곽 붕괴·회수 재배치를 실제 플레이 화면으로 확인하고, 확장 가능한 픽셀아트 제작 기준을 고정한다.

샘플 지형 범위는 기존 맵 셀 x30..65, y6..30의 광장·광화문·내곽이다. 충돌 맵을 바꾸지 않고 해당 범위에만 지형/배경 아트를 적용한다. 시설 4종과 기본 적 1종은 동일 종류의 표현을 전장 전체에서 공유하여 경계에서 외형이 튀지 않게 한다. 나머지 지형은 기존 표시를 유지하며 부분 적용임을 결과에 명시한다.

포함: 아래 최소 리소스, 표시 교체, 상태 연동, 기존 메뉴/재시작 유지, 두 해상도 캡처, 동일 전투 상태 비교, 새 release 성능.

제외: 새 전투 규칙·밸런스·경제·적 유형·보스·음향·화면 흔들림, 전체 맵 꾸미기, 전체 HUD 재설계, 새 카메라/해상도 체계. 시안에 보이는 요소를 새 게임 기능으로 추가하지 않는다.

## 전투·입력·성능 보존

기본 HP360/60, 18시설, 10존, seed20260913, 유한 웨이브1140체를 유지한다. 장승 차단/화차 비차단, 붕괴 후 외곽 점유 보존, 회수 화차 같은 ID, WP-004 메뉴 입력 해제 대기를 변경하지 않는다.

표시 비교용 `--art=greybox|sample`을 제공한다. 이는 렌더링 선택만 바꾸고 게임 데이터/난수/자동 모드 설정을 바꾸지 않는다. 같은 seed와 명령을 넣은 두 모드의 구조화 전투 상태를 run_id 제외 동일하게 비교한다. 비교 지점은 초기, 붕괴 직전/직후, 재배치 직후, 승패 종료다.

release 성능은 같은 바이너리·장비·해상도·vsync0에서 greybox/sample 양쪽을 collapse_move와 collapse_combat 각각 warmup10초+measure60초 측정한다. 샘플 모드에서는 전장 전체 적 1,000체가 새 스프라이트로 렌더되어야 한다. 각 모드의 실제 리소스/설정·구현 SHA·exe 해시를 기록한다. 기존 WP 증거는 덮어쓰지 않는다.
