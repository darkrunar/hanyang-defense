# 콘텐츠 목록

2026-09-28 / 기획 정리본 / 기준 커밋 bf228c0 및 현재 로컬 문서

콘텐츠는 플레이어가 만나고 배치하고 지키는 대상과 플레이 장면이다. 동작 규칙은 [시스템 목록](SYSTEM_CATALOG.md)에 정리한다. 목록 등재는 구현 승인이나 완료 판정이 아니다.

## 상태와 근거

- 기존 명세: 기존 WP에 규칙이 정의됨. 이번 작성에서 실행/PR 최신 상태를 재검증한 것은 아님.
- 후속 계획: DRAFT WP 또는 확장 계획에 포함. 세부 규칙 확정 필요.
- 후보: 상위 비전·대화에서 검토한 내용. 전투 역할과 제작 범위 미정.
- 재검토: 기존 명세는 있으나 현재 기획 재구축에서 필요성/역할 확인 필요. 삭제 결정 아님.
- 로컬 작업 중: 미커밋 체크리스트/코드가 존재. 통합·플레이 검증 미확인.

근거: [GAME_DESIGN](GAME_DESIGN.md), [CORE_LOOP](CORE_LOOP.md), [확장 계획](GAMEPLAY_EXPANSION_PLAN.md), [재구축 계획](DESIGN_VALIDATION_REBUILD_PLAN.md), backlog/WP-001~010. 현행 문서와 대화의 후보를 구분한다. 다른 브랜치의 구현 현황은 해당 결과/PR 확인 후 갱신한다.

## 다음 정리 순서

재구축 Q1~Q5에서 방어 대상·적 공격·조작·공방·승패를 정하고 V0~V1에 필요한 콘텐츠만 선정한다. 이후 물자·연결·재편을 한 단계씩 검증한다. 장승 종류는 전승 자료 선택과 전투 역할 결정을 각각 기록한다. 봉수망의 삭제나 장승 신규 능력 채택은 아직 결정되지 않았다.
