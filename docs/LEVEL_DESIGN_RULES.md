# 레벨 디자인 규칙

2026-09-28 · 기획 초안 / 구현·플레이 검증 전

목표는 **적이 어디로 와서 무엇을 공격하는지 이해하고, 배치를 바꿔 방어 결과를 바꾸는 것**이다. 초반 4개 스테이지는 기존 맵 체크리스트를 구체화한다. 이후는 기능 의존성을 가진 확장안이다. 이 문서만으로 기존 WP를 READY로 승격하거나 방어 대상·승패 재정의의 미결정 항목을 확정하지 않는다.

기준: [단계별 설계](LEVEL_DESIGN_STAGES.md), [맵 체크리스트](STAGE_MAP_TEST_CHECKLIST.md), [검증 재구축](DESIGN_VALIDATION_REBUILD_PLAN.md), [개발 10계명](DEVELOPMENT_TEN_PRINCIPLES.md), [콘텐츠 목록](CONTENT_CATALOG.md), [시스템 목록](SYSTEM_CATALOG.md).

## 1. 공간과 공방 계약

| ID | 규칙 | 확인 방법 |
|---|---|---|
| LD-01 | 최종 목표는 성벽·성문을 제외한 성 내부에 둔다. 성문은 중간 방어선이며 파괴가 자동 패배를 의미하지 않는다. 구체적 HP·공격·승패는 전투 프로필에서 지정 | 외부/성벽/성문 목표 거절, 내부 목표 허용. 외곽 거점 붕괴와 성문 파괴를 별개 사건으로 기록 |
| LD-02 | 화면 밖 한 생성 중심 → 외곽 진입점 → 성문 → 내부 목표의 순서를 유지 | 성문을 닫으면 외부에서 내부로 도달 불가. 열면 도달 가능. 문을 지났다가 외부 목표로 되돌아가는 지도 거절 |
| LD-03 | 무작위 생성 범위 전체가 화면 밖에 있고 유효 접근로를 갖게 한다 | 정수 셀 기반이면 가능한 생성 셀 전수 검사 + 고정 seed 표본. 12개 표본 PASS를 전수 보장으로 표기하지 않음 |
| LD-04 | 공격 가능 영역과 실제 이동 경로를 겹치게 한다 | 화차의 사거리뿐 아니라 타깃 존·관측·연결·발사 조건까지 확인. 길 위에 적이 보여도 타깃 존 밖이면 학습 실패 |
| LD-05 | 시설 2×2 점유와 길 폭을 함께 설계한다 | 후보 설치점의 전체 점유 셀·경로 유효성 검사. 화차는 D-011 통행 비차단 유지. 장승은 현행 설치 거절 규칙을 따름 |
| LD-06 | 지형은 접근 방향·노출 시간·집결 위치 중 하나를 실제로 바꿔야 한다 | 같은 생성 좌표·seed·전투 설정으로 지형만 켜고 끈 A/B 비교. 장애물 개수만으로 통과 불가 |

현재 에디터의 성문 셀은 경로 통과 지점이다. 성문 HP·파괴·지속 공격이 작동한다는 증거가 아니다. 초기 맵 실험의 승패·적 피해 방식은 기존 검증된 전투 프로필을 명시해 재사용하고, 새로운 공성 규칙은 별도 통합 뒤 평가한다.

## 2. 학습과 선택

1. **한 레벨에 새 핵심 행동 하나.** 설명 → 안전한 첫 시도 → 압박 속 반복 → 결과 확인 순서로 배치한다. 새 지형·새 적·새 경제를 동시에 처음 공개하지 않는다.
2. **첫 화면에서 적 접근·성문·목표가 읽혀야 한다.** Stage001의 목표 식별 기준은 기존 10초를 사용한다. 적 접근은 예고하되 시작 전 강제 대기보다 준비 완료 입력을 우선 검토한다.
3. **선택 두 개에는 서로 다른 장단점이 있어야 한다.** 전방 조기 공격과 후방 집중 공격처럼 비교한다. 기능상 동일한 좌우 대칭 자리는 선택 두 개로 세지 않는다.
4. **실패 원인을 보여 준다.** 사거리 밖, 관측 단절, 화력 부족, 경로 변경, 목표 피해를 구분해 기록한다. 설명 없는 갑작스러운 공격 방향 변경을 난도로 삼지 않는다.
5. **잘 막으면 계속 막을 수 있다.** 후퇴를 가르치려고 정상 플레이의 승리를 강제 붕괴로 바꾸지 않는다. 붕괴 분기는 별도 재현 fixture에서 시험한다.
6. **보상은 다음 행동과 연결한다.** 건설 도입 뒤에는 물자·비용·부족액을 표시하고, 구매 전에 대응할 다음 위협을 보여 준다. 새 재화·합성·해금을 자동 추가하지 않는다.

연결 원칙: T-01 위험/보상, T-02 압박/해소, T-04 즉시 피드백, T-06 빠른 재도전, T-07 선택의 개성, T-08 다음 목표, T-09 강제 패배 방지, T-10 설정 재현.

## 3. 난도와 조정 순서

| 축 | 조절 대상 | 혼동 방지 |
|---|---|---|
| 시간 압박 | 출현 간격·총량·휴식 | 웨이브 수만 늘리면 길이 변화일 수 있음. 생성률만 올릴 때 총량·적 능력은 고정 |
| 공간 판단 | 장애물·병목·유효 사격 구간 | 지형 실험에서는 적 수·속도·시설 성능 고정 |
| 투자 판단 | 시작 물자·구매 가능 수·보상 시점 | 경제 통합 확인 전 수치를 맵 tuning에 넣었다고 구현으로 간주하지 않음 |
| 정보 판단 | 감지·망 연결 | 공유 정보로 실제 공격이 달라지는 비교가 없으면 봉수 도입 보류 |
| 복구 판단 | 중간 방어선 손실·회수·재건 | 손실 예고, 입력 시간, 물자와 설치 슬롯을 함께 보장 |

실험 시작값: 압박 비교는 기본 생성률을 1.0×/1.25×로 비교하고 다른 값을 고정한다. 이는 새 기획 실험값이지 현행 밸런스 확정값이 아니다. 큰 수치 증가 전에 사격 가능 구간과 배치 대안부터 고친다. 재미·승률 합격선을 결과를 본 뒤 소급 설정하지 않는다.

## 4. 제작과 단계 통과

| 게이트 | 제출물 | 통과 조건 |
|---|---|---|
| G0 설계 | 목표 행동·맵·적/시설·전투 프로필·승패·미결정 | 기능 의존성, 공방 규칙, A/B 통제 조건이 명시됨 |
| G1 지도 | 편집 가능한 맵 파일·설정·검사 로그 | 목표 내부, 성벽 봉쇄, 생성 유효성, 경유 순서, 설치 가능 영역, 저장/불러오기 일치 |
| G2 전투 | 실제 전투 실행·입력/사격/피해 로그 | 지도 데이터가 전투에서 사용됨. 에디터 이동 점만으로 대체 불가 |
| G3 경험 | 정상 속도 영상·관찰 기록·A/B 비교 | 해당 레벨의 학습 행동과 결과 차이가 관찰됨. 참가자·힌트·숙련도 기록 |
| G4 회귀 | 영향 범위 시험·필요한 성능 증거 | 기존 AC 유지. 대량 전투에 영향이 있으면 기존 1,000체 조건도 재측정 |

상태는 설계 DRAFT → 맵 제작 → 전투 연결 → 플레이 검증 → 채택으로 기록한다. 기능 PASS/FAIL/NOT RUN과 경험 충족/보완 필요/미평가를 분리한다. 현재 작성은 G0 준비이며 G1~G4 완료가 아니다.

각 레벨 리포트는 지도 전체 이미지, 주요 선택 지점 이미지, 정상 속도 플레이 영상, 입력·사격·피해·구매·승패 시각, seed/설정/구현 SHA를 포함한다. 영상에는 수동/자동 실행, 배속, 편집 여부를 표시한다. 미리보기와 실제 전투를 분리한다.

## 5. 선행 수정

2026-09-28 테스트 기준 R-01은 지형 추가 전후 12/12 경로 동일, R-02는 성 밖 목표 (31,30)도 validator PASS였다. 해당 실행 기준은 97f15a6 + 미커밋 맵 에디터 변경이며 원격 최신 상태 판정이 아니다.

먼저 R-02 목표 영역 검사와 R-01 Stage003 지형안을 검증한다. 다음으로 Stage001 맵 데이터의 실제 전투 진입을 연결한다. 이 세 가지가 확인되기 전 후속 스테이지를 플레이 완료로 표시하지 않는다. 기존 증거는 보존하고 새 결과를 별도 실행 폴더에 남긴다.
